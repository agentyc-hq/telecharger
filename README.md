# AGENTYC : télécharger l'appli

Ce dépôt ne contient que les fichiers d'installation d'AGENTYC, l'appli où ton agent travaille avec toi, sur ton ordinateur.

**Pour télécharger** : va sur [agentyc.fr/telecharger](https://agentyc.fr/telecharger), ou prends le fichier de la [dernière version](https://github.com/agentyc-hq/telecharger/releases/latest).

- **Mac** (puce Apple M1 ou plus récent) : `AGENTYC-x.y.z-arm64.dmg`.
- **Windows** : bientôt.

L'empreinte SHA-256 de chaque fichier est donnée dans les notes de sa version : tu peux la comparer avec `shasum -a 256 <fichier>`.

Le code de l'appli n'est pas ici.
